## 🆕 ฟีเจอร์ใหม่ใน v2.0

- ✅ **VAT 7%** — แยกแสดงราคาก่อน VAT + VAT + รวม ในใบเสร็จ
- ✅ **2 รูปแบบใบเสร็จ**:
  - ใบกำกับภาษีอย่างย่อ (default — ออกทุกบิล)
  - ใบกำกับภาษีเต็มรูป (กดออกตอนลูกค้าขอ)
- ✅ **รองรับ thermal printer 80mm** (เพิ่ม CSS print)
- ✅ **เลขประจำตัวผู้เสียภาษี / สาขา** ในใบเสร็จ
- ✅ **เปิด/ปิด VAT ได้** ในแท็บตั้งค่าร้าน

## 🚀 ขั้นตอนติดตั้ง

### ครั้งแรก (สร้างใหม่)
1. ลบไฟล์ `index.html` เก่าใน GitHub repo
2. อัปโหลดไฟล์ใหม่ทั้งหมด: `index.html`, `styles.css`, `app.js`, `api.js`, และโฟลเดอร์ `modules/`
3. เปิด `https://dearsica.github.io/POS_-/`

### วิธีอัปโหลดโฟลเดอร์เข้า GitHub
1. ใน repo → **Add file → Upload files**
2. **ลากทั้งโฟลเดอร์** `pos-v2` ไปวาง (จะรักษาโครงสร้างไฟล์)
3. Commit changes

## 🧾 วิธีใช้ VAT

### Step 1: ตั้งค่า VAT
1. ไปแท็บ **⚙️ ตั้งค่าร้าน**
2. ติ๊ก ✓ **"ร้านนี้จดทะเบียน VAT"**
3. กรอก **เลขประจำตัวผู้เสียภาษี** (13 หลัก)
4. กรอก **สาขา** (เช่น "สำนักงานใหญ่")
5. **บันทึก**

### Step 2: ราคาขาย
- ราคาขายในระบบ **รวม VAT แล้ว** (เช่น ขาย 107฿ = ลูกค้าจ่าย 107฿)
- ระบบจะแยก VAT อัตโนมัติบนใบเสร็จ

### Step 3: ตอนขาย
- ขายตามปกติ → ระบบออก **ใบกำกับภาษีอย่างย่อ** อัตโนมัติ
- ถ้าลูกค้าขอ **ใบกำกับภาษีเต็มรูป** → กดปุ่มในใบเสร็จ → กรอกชื่อ/ที่อยู่/เลขผู้เสียภาษีของลูกค้า
